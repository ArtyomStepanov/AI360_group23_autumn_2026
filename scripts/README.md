# Первый эксперимент: размер батча, качество и sharpness

Второй эксперимент с сеткой learning rate × batch size описан в
[exp2_README.md](exp2_README.md).

[exp1.py](exp1.py) сравнивает качество классификации и остроту решения при
разных размерах обучающего батча. Для каждой комбинации модели, числа эпох,
размера батча и seed модель обучается заново. Затем вычисляются test loss,
test accuracy и sharpness на обучающей выборке.

## Модели и данные

| Setup | Модель | Датасет | Число классов |
| --- | --- | --- | --- |
| C1 | [C1](../models/instances/C1.py) | CIFAR-10 | 10 |
| C2 | [C2](../models/instances/C2.py) | CIFAR-10 | 10 |
| C3 | [C3](../models/instances/C3.py) | CIFAR-100 | 100 |
| C4 | [C4](../models/instances/C4.py) | CIFAR-100 | 100 |

Используются стандартные train/test-разбиения torchvision. Данные скачиваются
автоматически в `datasets/` в корне проекта. Изображения преобразуются в тензоры
и нормализуются по каналам; случайная аугментация не применяется.

| Датасет | Средние RGB | Стандартные отклонения RGB |
| --- | --- | --- |
| CIFAR-10 | (0.4914, 0.4822, 0.4465) | (0.2470, 0.2435, 0.2616) |
| CIFAR-100 | (0.5071, 0.4867, 0.4408) | (0.2675, 0.2565, 0.2761) |

Особенности архитектур и их соответствие моделям из статьи описаны в
docstring классов и [README моделей](../models/instances/README.md).

## Параметры эксперимента

| Параметр | Значение |
| --- | --- |
| Число эпох | 5, 10, 20 |
| Seeds | 67, 69, 228, 360, 1488 |
| Оптимизатор | Adam, lr=0.001, остальные параметры по умолчанию |
| Функция потерь | CrossEntropyLoss |
| Устройство | CUDA при наличии, иначе CPU |
| Загрузчики обучения и sharpness | workers=8 |
| Батч для оценки и sharpness | min(размер test-выборки, 2048) |

Размеры обучающего батча — объединение степеней двойки от 64 до размера
train-выборки и целых значений 1–10% её размера. Повторы удаляются.
Для train-выборки из 50 000 примеров сетка содержит 20 значений:

```text
64, 128, 256, 500, 512, 1000, 1024, 1500, 2000, 2048,
2500, 3000, 3500, 4000, 4096, 4500, 5000, 8192, 16384, 32768
```

Полная сетка содержит 4 × 3 × 20 × 5 = 1200 прогонов. Параметры задаются
в `SETUPS`, `get_batch_sizes()` и `main()`; аргументов командной строки нет.

При обучении данные перемешиваются, последний неполный батч отбрасывается.
Поэтому при одинаковом числе эпох разные размеры батча дают разное число
обновлений весов и могут учитывать разное число примеров. Fit сбрасывает веса
под заданным seed; на CUDA обучение использует AMP.

Sharpness вычисляется через `compute_sharpness` с epsilon=5e-4,
maxiter=10, subspace_dim=100 и optimize=False. Для поиска используется seed
текущего прогона. Это приближённая оценка нормированного увеличения train loss
в процентах; её контракт описан в [README метрик](../metrics/README.md).

## Запуск

Из корня проекта, в выбранном Python-окружении:

```bash
python -m pip install -r requirements.txt
python scripts/exp1.py
```

Первый запуск требует доступа к интернету для скачивания CIFAR.
Пути данных и результатов определяются относительно корня проекта.

## Результаты и повторный запуск

Результаты записываются в `results/c1_c4_results.csv`. Одна строка соответствует
полностью завершённому прогону; она добавляется после обучения и обеих оценок.

| Поле | Значение |
| --- | --- |
| setup | C1, C2, C3 или C4 |
| dataset | CIFAR10 или CIFAR100 |
| model | Имя класса модели |
| epochs | Число эпох |
| batch_size | Размер обучающего батча |
| seed | Seed прогона |
| loss | Средний CrossEntropyLoss на test-выборке |
| accuracy | Доля правильных ответов на test-выборке, от 0 до 1 |
| sharpness | Острота на train-выборке, в процентах |

Повторный запуск пропускает комбинации `(setup, dataset, model, epochs,
batch_size, seed)`, уже записанные в CSV. Прерванный до записи строки прогон
обучается заново. Несовместимый заголовок CSV вызывает ошибку.

Ключ пропуска не включает lr, нормализацию, параметры sharpness или изменения
реализации модели. Для отдельного эксперимента с такими изменениями нужно
задать другой `results_csv` либо переместить прежний файл результатов.

Скрипт сохраняет отдельные значения метрик. Веса моделей, история обучения,
агрегаты по seeds и графики не сохраняются.
