# Локальный второй эксперимент

[exp2_local.py](exp2_local.py) запускает C4 на CIFAR-100 по умолчанию.
Используются 20 learning rate × 20 размеров батча = 400 независимо обученных
моделей, по 10 эпох, Adam и seed=67. Сетка learning rate и анализ результатов
переиспользуются из `exp2.py`.

Размеры обучающего батча по умолчанию:

```text
8, 16, 24, 32, 40, 48, 56, 64, 80, 96,
112, 128, 144, 160, 176, 192, 208, 224, 240, 256
```

Из 50 000 train-примеров 45 000 используются для обучения и 5 000 для выбора
оптимального learning rate. Отдельные 10 000 test-примеров используются для
отчёта. Минимум loss, максимум accuracy и минимум sharpness анализируются
отдельно; линейность зависимости проверяется по результатам, а не задаётся
при обучении.

## Запуск

Из корня проекта с активированным окружением сначала выполните один прогон:

```bash
python scripts/exp2_local.py --limit 1
```

Затем продолжите оставшуюся сетку с теми же параметрами:

```bash
python scripts/exp2_local.py
```

CUDA выбирается автоматически, если доступна. Первый запуск скачивает CIFAR-100
в `datasets/`, если данных ещё нет. `--limit N` выполняет N дополнительных
незавершённых прогонов и сохраняет полную сетку из 400 комбинаций.

Результаты записываются отдельно в `results/exp2_local_C4/`: `config.json`,
`results.csv`, `checkpoints/`, `best_lr.csv`, `linearity.json`, `best_lr.png`
и `grid.png`. Повторный запуск пропускает записанные результаты. Если обучение
уже сохранило checkpoint, но оценка прервалась, повторяются только оценки.
Для пересчёта графиков без обучения:

```bash
python scripts/exp2_local.py --analyze-only
```

## Память и параметры

Для C4 матрица подпространства sharpness при `subspace_dim=100` занимает
примерно 5,6 GiB в float32. Дополнительно нужны память для решения системы,
модели и вычисления градиентов. Уменьшение батча оценки помогает только с
памятью на примеры, размер матрицы от него не меняется. 400 checkpoint-файлов
C4 занимают около 24 GB на диске.

По умолчанию оценка использует батч 64 и максимум из трёх стартов LBFGS.
Можно перенести sharpness на CPU, сохранив размерность подпространства;
потребуется достаточно оперативной памяти, вычисление может стать медленнее:

```bash
python scripts/exp2_local.py --sharpness-device cpu --output-dir results/exp2_local_C4_cpu_sharpness --limit 1
```

Или уменьшить размерность подпространства:

```bash
python scripts/exp2_local.py --sharpness-subspace-dim 10 --output-dir results/exp2_local_C4_p10 --limit 1
```

Это изменяет оценку sharpness: результаты p=10 нельзя напрямую сравнивать
с результатами p=100. Для продолжения любого из этих запусков повторите
ту же команду без `--limit 1`.

Другие параметры: `--setup C1|C2|C3|C4`, `--device cuda:0`, `--workers`,
`--eval-batch-size`, `--min-batch`, `--max-batch`, `--min-lr`, `--max-lr`,
`--seed`, `--sharpness-starts`. Сетка всегда содержит 20 × 20 комбинаций.
При изменении конфигурации или кода требуется новый `--output-dir`.
Для C1/C3 по умолчанию используются батчи 64–2048 и батч оценки 256;
для C2/C4 — 8–256 и 64. Каталоги результатов разделены по setup.
