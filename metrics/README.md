# Метрики

Пакет экспортирует BaseMetric, Accuracy и BinaryAccuracy. Функция sharpness
импортируется отдельно из [sharpness.py](sharpness.py).

## BaseMetric

BaseMetric — абстрактный интерфейс метрики с накоплением состояния.

| Метод | Контракт |
| --- | --- |
| reset() -> None | Очищает состояние предыдущей оценки |
| update(outputs, targets) -> None | Добавляет результаты одного батча |
| compute() -> float | Возвращает значение по всем накопленным батчам |

Outputs и targets — тензоры на устройстве оценки. Outputs передаются напрямую
из модели; преобразование в предсказания выполняет метрика. Update не должен
изменять входные тензоры, общие для всех метрик.

Evaluate вызывает reset перед проходом по датасету, update для каждого батча
внутри torch.no_grad(), затем compute. Один экземпляр хранит состояние одного
вычисления; повторный вызов evaluate сбрасывает его накопления.

## Оценка sharpness

Compute_sharpness — функция оценки модели, отдельная от BaseMetric.
Её аргументы включают model, dataset и device; вычисления требуют
градиентов. Вызов внутри torch.no_grad() не поддерживается.

Значения аргументов по умолчанию:

| Аргумент | Значение и смысл |
| --- | --- |
| criterion | None: средняя cross entropy; переданный criterion возвращает средний loss батча |
| batch_size | 1024; все примеры учитываются, включая последний неполный батч |
| epsilon | 5e-4; масштаб области возмущений |
| maxiter | 10; лимит итераций LBFGS, не число вычислений loss |
| subspace_dim | 100; None или значение >= числа параметров включает полное пространство |
| seed | 42 |
| workers | 0; число процессов загрузки данных |
| optimize | False; AMP включается только на CUDA |

Матрица случайного подпространства фиксируется на весь поиск. Матрицы не
перебираются. Функция возвращает float: нормированное увеличение loss,
умноженное на 100. Использует один запуск LBFGS с tanh-репараметризацией.
Границы координат — epsilon * (abs(A⁺ theta) + 1); при A=I используется theta.
Начальная точка случайная ненулевая. Для A, старта и DataLoader используются
локальные генераторы, глобальный seed PyTorch не меняется.

Функция проверяет непустой датасет и положительные batch_size, epsilon, maxiter,
а также subspace_dim (либо None). Модель и criterion переносятся на device;
устройство обратно не восстанавливается. Исходный режим модели восстанавливается
через finally.
Параметры и стандартные буферы модели не меняются при оценке. Для подпространства
A⁺ theta вычисляется один раз до оптимизации через lstsq; плотная матрица A
занимает O(n*p) памяти и требует дополнительной памяти для решения.

Область возмущений функции соответствует формулам (3)–(4), Metric 2.1 в
[статье Keskar et al.](https://arxiv.org/abs/1609.04836). Алгоритм поиска
отличается от L-BFGS-B авторов. При малом epsilon стандартные пороги LBFGS могут
остановить поиск слишком рано. Нулевая оценка не доказывает плоскость минимума.
