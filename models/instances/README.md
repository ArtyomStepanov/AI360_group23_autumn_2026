# Реализации моделей

Доступны [CNN](CNN.py), [DNN](DNN.py) и [ShallowNN](ShallowNN.py).
Модели из статьи Keskar et al. представлены отдельными классами:
[F1](F1.py), [F2](F2.py), [C1](C1.py), [C2](C2.py), [C3](C3.py), [C4](C4.py).
Каждый из этих шести классов создаётся без аргументов, с фиксированным числом
классов своей задачи. C1–C4 используют существующие ShallowNN/DNN как основу.
Конструкторы, формы входов и выходов и особенности описаны в docstring классов.
Общий интерфейс: [AbstractModel](../README.md).
