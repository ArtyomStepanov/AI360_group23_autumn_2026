# Состояния моделей

Каталог для файлов state_dict, сохраняемых через save_model из
[models/utils.py](../utils.py). Содержимое включает параметры и буферы модели;
архитектура и состояние обучения не сохраняются.

Load_model загружает файл в существующую совместимую модель. Полный контракт
приведён в [README моделей](../README.md), пример — в
[корневом README](../../README.md).
