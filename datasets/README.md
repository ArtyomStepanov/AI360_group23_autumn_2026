# Датасеты

Fit и evaluate принимают наследника torch.utils.data.Dataset с доступом по
индексу. IterableDataset текущими циклами не поддерживается.

## Интерфейс

| Метод | Контракт |
| --- | --- |
| __len__() | Возвращает число примеров |
| __getitem__(index) | Возвращает пару тензоров (x, y) для одного примера |

X — вход модели, y — целевое значение. Пример не содержит батчевую ось:
её добавляет стандартный DataLoader. Формы примеров должны позволять объединение
в батч. Собственные collate_fn через fit/evaluate сейчас не передаются.

Оба цикла вызывают `.to(device)` у x и y. Словари, вложенные структуры и строки
вместо этих тензоров текущим контрактом не поддерживаются. Обычный формат выдачи
датасета — CPU-тензоры; перенос на устройство выполняют циклы.

## Форматы для классификации

| Сценарий | X одного примера | Y одного примера |
| --- | --- | --- |
| CNN/DNN/ShallowNN с CrossEntropyLoss | float32, `(3, 32, 32)` | Скаляр long, индекс класса |
| Бинарная классификация с BCEWithLogitsLoss | Вход выбранной модели | float32, скаляр либо `(1,)`, значение 0 или 1 |

Для C классов индексы лежат в `[0, C - 1]`. Соответствие классов индексам должно
совпадать во всех частях датасета. После объединения в батч метки для
CrossEntropyLoss имеют форму `(N,)`. Для BCEWithLogitsLoss форма меток должна
совпадать с формой выхода модели: `(N,)` либо `(N, 1)`.

Масштаб значений входов и нормализация определяются конкретным датасетом;
fit/evaluate не выполняют преобразования данных, кроме переноса на устройство.

## Ограничения размера

| Цикл | Ограничения | Последний неполный батч |
| --- | --- | --- |
| fit | batch_size >= 2, len(dataset) >= batch_size | Отбрасывается |
| evaluate | batch_size >= 1, len(dataset) > 0 | Сохраняется |

Общий пример с TensorDataset приведён в [корневом README](../README.md).
