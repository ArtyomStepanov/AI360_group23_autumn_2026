# Логгеры

Пакет экспортирует [BaseLogger](base.py) и [LossLogger](loss.py).

## BaseLogger

BaseLogger — абстрактный интерфейс:

| Метод | Контракт |
| --- | --- |
| reset() -> None | Сбрасывает накопленную историю |
| __call__(model: nn.Module, loss: float) -> None | Получает текущую модель и loss батча |
| get_history() -> Any | Возвращает историю в формате конкретной реализации |

Fit вызывает логгер после обработки каждого батча. При AMP GradScaler может
пропустить шаг optimizer при нечисловых градиентах; логгер всё равно вызывается. Передаётся исходный экземпляр
модели, а не снимок её состояния. Loss соответствует вычислению до этого шага
и передаётся как float без графа вычислений.

Fit не вызывает reset автоматически. Повторное использование одного логгера
продолжает историю; явный reset начинает новую. Logger=None в TrainConfig
отключает логирование.
